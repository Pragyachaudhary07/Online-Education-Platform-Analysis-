# Online Education Platform Analysis

This project focuses on analyzing an online education platform using the Udemy courses dataset. The goal is to understand course performance and user engagement using data science techniques.

---

## Objective

- Analyze course popularity and user engagement  
- Perform data cleaning and preprocessing  
- Visualize data using Matplotlib and Seaborn  
- Extract meaningful insights from real-world data  

---

## Dataset

- Source: Kaggle (Udemy Courses Dataset)  
- Contains information such as:
  - Course title  
  - Price  
  - Number of subscribers  
  - Number of reviews  
  - Course level  
  - Content duration  

---

## Data Cleaning

- Removed missing values  
- Removed duplicate records  
- Cleaned column names  
- Converted data types  
- Removed irrelevant categories  

---

## Visualization

### Matplotlib:
- Line Plot  
- Histogram  
- Bar Plot  

### Seaborn:
- Heatmap  
- Countplot  
- Boxplot  
- Violin Plot  
- Pairplot  

---

## Key Insights

- Courses with more reviews have more subscribers  
- Beginner-level courses are most common  
- Price has less impact on popularity  
- Few courses dominate in subscriber count  

---

## Conclusion

The analysis shows that user engagement plays a key role in course success. Data visualization helps uncover patterns and trends in online learning platforms.
